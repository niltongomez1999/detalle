Capas del corazón

Página web interactiva para regalar a alguien especial. Al abrir la página, verás una pila de "capas" (sobres). Cada capa se puede abrir para mostrar un mensaje corto; al final se revela una carta principal.

Cómo usar

1. Abrir `index.html` en un navegador moderno.
2. Tocar "Empezar" y pulsa/da click en la capa superior para abrirla. En móviles puedes hacer "swipe up" para abrir la siguiente.

Personalizar mensajes

- Edita `script.js` y modifica el array `messages` y la variable `finalLetter` con tus propias frases y carta.
	- En esta versión la carta final está firmada por "Nilton". Si quieres cambiar la firma, edita `finalLetter` en `script.js`.

Compatibilidad

Funciona en navegadores modernos en escritorio y móviles. La página es responsive y diseñada para verse bien en pantallas pequeñas.
